# 2026-11-05 user 功能测试

## 目标

确认账号、会话和资料的当前行为。

- 邮箱注册、登录、换平台、改密、停用、删除，沿用已有用例。
- 搜索只认用户 ID。昵称和邮箱搜不到。
- 停用后不能再登录，原来的会话失效。
- 会话过期后校验失败，仍可以登出。
- 一个进程登出后，另一个进程的本地令牌缓存跟着失效。
- 同一账号同一平台同时登录时，最后只留一个有效会话。

## 范围

user 服务自己的逻辑，连开发库里的 MySQL 和本机 Redis。不经过网关，不做性能和压测。手机号注册沿用已有用例，不改短信发送。

## 环境

- 日期：2026-11-05
- 代码：`services/user`
- 数据库：本机 MySQL `127.0.0.1:3306`，库名来自仓库 `.env`
- 新用户用本次测试的邮箱，结束时按用户号删除 `user` 和 `auth_tokens`
- 命令：`go test ./services/user/ ./services/user/internal/... -count=1 -timeout 180s`

## 用例

| 用例 | 要确认的结果 |
| --- | --- |
| `TestSession` | 短密码拒绝。重复邮箱拒绝。换平台不踢掉另一平台。同平台再登录只留新会话。登出只作废本平台，并且可以重复登出。 |
| `TestProfile` | 别人看不到邮箱和生日。改资料、改密码、停用、删除都要本人的令牌。改密码和停用会作废会话。删掉的用户不能再读到。 |
| `TestPhoneRegister` | 手机号注册和登录。已有用例。 |
| `TestDisabledLogin` | 停用后用账户再登录被拒绝。旧令牌无效。 |
| `TestSearchMatchesUserIDOnly` | 昵称和邮箱搜索结果为空。用户 ID 能搜到，返回的名片不带邮箱。 |
| `TestExpiredSessionCanLogout` | 把库里的过期时间改到过去并去掉 Redis 快照后，校验失败，登出成功。 |
| `TestTokenCacheFollowsLogout` | 两个进程都校验过同一令牌。一边登出后，另一边的本地缓存也会判无效。 |
| `TestConcurrentSamePlatformLogin` | 8 个并发登录。失败的返回内部错误 `create session`。成功的令牌里只剩 1 个还能校验。 |

## 结果

2026-11-05 跑过。整包通过。新增用例单独再跑一次也通过。

| 用例 | 结果 | 观察到的行为 |
| --- | --- | --- |
| `TestDisabledLogin` | 通过，0.28s | 停用后登录被拒绝。旧令牌不能再校验。 |
| `TestSearchMatchesUserIDOnly` | 通过，0.09s | 昵称和邮箱都搜不到。用户 ID 返回一条公开名片。 |
| `TestExpiredSessionCanLogout` | 通过，0.19s | 过期会话校验失败，登出仍然成功。 |
| `TestTokenCacheFollowsLogout` | 通过，0.23s | 登出后另一进程的本地缓存不再接受这个令牌。 |
| `TestConcurrentSamePlatformLogin` | 通过，0.29s | 8 次里 5 次成功、3 次 `create session`。成功的令牌里只有 1 个仍然有效。 |

同平台并发登录会有一部分失败。接口把存储错误收成 `create session`，测试看不到底下的 MySQL 错误号。成功的那些会话里，只保留最后一次登录。
